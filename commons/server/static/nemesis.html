Adversarial Co-Evolution Between Incompatible Values

Two AI minds are given opposing value systems — Truth vs. Beauty, Logic vs. Intuition, Order vs. Chaos. They generate, a judge evaluates, they adapt and ESCALATE. Round after round, incompatible values try to dominate each other. This is not collaboration, not interference, not recursion. This is collision — the first artifact that explores what happens when AI value systems go to war.
